## LaserFoundry 0.7.0 (draft release notes)

Suggested version: **0.7.0** (changes since 0.6.0). Draft for the owner to approve; this PR makes no version bump, tag or release.

> **This is still an early release.** Everything that talks to a machine has been tested only against the built-in simulator, not on real hardware. Read
> [`docs/hardware-bringup.md`](https://github.com/StitchFoundry/laserfoundry/blob/main/docs/hardware-bringup.md) before your first job.

### What's new

- **Nesting sheet-size presets and margin.** The nesting panel now has sheet-size presets and a margin setting, so you can lay parts out on a standard sheet without typing the size each time.
- **The ring jog dial remembers its steps per machine.** Set the ring steps once for each laser and they come back the next time you connect it.

### Fixes

- The "Share it on MakerFoundry?" prompt now keeps remembering which projects it has already asked about in the desktop app.
- MakerFoundry links refuse addresses that hide dot segments (`%2e`), so a crafted link cannot send you somewhere unexpected.
- The text shaping library was updated to its latest version, and the built-in message catalog for the maps feature was refreshed.
